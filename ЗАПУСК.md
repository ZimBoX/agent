# Как вручную поднять всё локально

Порядок важен: сначала БД (Docker), потом бэкенд. Клиент (десктоп) ставится
отдельно инсталлятором и сам ходит на бэкенд по `http://localhost:5149`.

## 1. Docker Desktop (база данных)

1. Запусти **Docker Desktop** (через меню Пуск) и дождись, пока в трее иконка
   кита перестанет мигать — демон готов за ~10–30 сек после старта.
2. В корне проекта подними Postgres:

   ```powershell
   docker compose up -d
   ```

   Проверить, что контейнер поднят:

   ```powershell
   docker ps
   ```

   Должна быть строка `agent-postgres-1 ... Up ...` на порту `5432`.
   Данные хранятся в volume `postgres_data` и переживают перезапуски.

> Если бэкенд отвечает 500 на запросах — почти всегда это значит, что Docker/
> Postgres не поднят (например, после сна/перезагрузки машины). Сначала
> проверяй `docker ps`.

## 2. Бэкенд (API)

Бэкенду нужен ключ агрегатора в переменной окружения `AITUNNEL_API_KEY`
(в файлы его не пишем — только инлайном на время запуска). PowerShell:

```powershell
$env:AITUNNEL_API_KEY = "СЮДА-КЛЮЧ-sk-aitunnel-..."
dotnet run --project backend\ClaudeAssistant.Api --launch-profile http
```

Готово, когда в консоли появится:

```
Now listening on: http://localhost:5149
```

Проверка снаружи: `http://localhost:5149/admin` (веб-панель админа,
логин/пароль по умолчанию `admin` / `admin`).

Остановить — `Ctrl+C` в окне бэкенда.

## 3. Клиент (десктоп)

Ставится один раз инсталлятором `Install ClaudeAssistant.exe` (тонкий
установщик — качает последнюю сборку с бэкенда). После установки запускается
из меню Пуск / значка в трее и работает, пока поднят бэкенд.

## Частые проблемы

| Симптом | Причина | Что делать |
|---|---|---|
| Бэкенд 500 на всех запросах | Postgres не поднят | `docker ps` → `docker compose up -d` |
| `backend=000` / не отвечает | Процесс бэкенда не запущен | Заново шаг 2 |
| «Переменная AITUNNEL_API_KEY не задана» | Забыл `$env:AITUNNEL_API_KEY` | Задать ключ перед `dotnet run` |
| Docker команды не работают | Docker Desktop не запущен | Запустить Docker Desktop, подождать |
